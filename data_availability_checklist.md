# Polaris CropPilot: Data Availability Checklist (tasks 0.09–0.25)

Fill in by opening each source in the browser (about an hour in total). Leave a cell blank until checked; write `none` if checked and missing.

- **Years found:** first–last season available for that row, e.g. `1998-99 to 2021-22`, and any gaps.
- **Format:** CSV, XLSX, PDF table, API, binary grid, web report.
- **Login needed:** yes / no / free registration.
- **Notes:** naming quirks, units (e.g. cotton in bales), district names used, file size.

Districts not in Census 2011 (Vijayanagara, created 2021) will likely appear under Ballari. Yadgir (created 2010) may appear under Kalaburagi in older years.
